# token at Kaggle > Settings > API and save it as
#     ~/.kaggle/kaggle.json          (Linux/macOS)
#     %USERPROFILE%\.kaggle\kaggle.json   (Windows)
# `python -m apexgpt hub check` tells you when both halves are in place.
